What the communication paper changes

The Stephens–Silbert–Hasson result makes the next experiment less vague: do not fuse two gels. Keep two private interiors and one narrow channel, then measure whether task-useful coupling appears, whether lead/lag structure changes with learning, whether prediction tracks success, and whether the pair can repair a broken code. That is the Phase II gate set in DIALOGUE.md.

Committed Python receipts are generated by python gates.py. Browser dynamics use the same ingredients—fast excitation, refractory state, eligibility, directed slow material—but are tuned for interactive visualization rather than numerical identity with the Python runner.
