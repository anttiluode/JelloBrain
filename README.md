# JelloBrain

### Can meaningless signals write a medium that remembers order, computes, negotiates a private code — and learn when inherited geometry is lying to its launcher?

**Live Phase I:** https://anttiluode.github.io/JelloBrain/  
**Live Phase II dialogue lab:** https://anttiluode.github.io/JelloBrain/dialogue.html  
**Live S-series spatial launcher lab:** https://anttiluode.github.io/JelloBrain/spatial.html

This repo takes the next step after [GelatinIsland](https://github.com/anttiluode/GelatinIsland). In that world, activity built geometry and geometry routed later activity. Here the traffic becomes a tiny artificial language — and then the geometry itself becomes an attacker.

> **Words are pokes that can become roads. Roads change what later pokes can do.**

Six meaningless primitives — `A B C D E F` — enter a writable 2-D dynamical substrate. A pseudoword is only a temporal sequence such as `ABC` or `ACB`. There are no embeddings, pretrained models, semantic labels, or stored word IDs. Fast excitation can be erased while slow directed material remains.

The project now has three increasingly hard stages:

```text
Phase I     one spatial gel
            ordered signals -> persistent operator geometry

Phase II    two private protocol gels
            interaction -> pair-specific pulse convention

S-series    one full spatial body + launch boundary
            inherited geometry -> prediction -> residual -> repair
```

The next hard gate is to combine all three: **two full spatial bodies whose launch events create both an external pulse and a private corollary-copy signal.**

## The spatial failure that became the S-series

Moving Phase II directly into full `JelloWorld` bodies exposed a serious confound. With naturally aligned input/output ports, **virgin geometry solved the task before learning**. After physically swapping the output wires, that same inherited geometry became exactly wrong, and naive reward-modulated replay could not escape it.

Rather than tune that failure away, the repo now freezes it as S0–S2 and asks a sharper question:

> **How can a launch boundary distinguish the road the body inherited from the road experience has made relevant?**

The S-series deliberately gives one full spatial body two strong inherited lanes:

```text
A ==================> C

F ==================> D
```

`A/F` are private cue ports and `C/D` are candidate axon-like launch ports. A two-wire channel is then physically swapped.

Run:

```bash
python spatial_gates.py
```

Frozen receipt: [`results/spatial_gates.json`](results/spatial_gates.json). Full audit: [SPATIAL_RESULT.md](SPATIAL_RESULT.md).

| Gate | Result | What it says |
|---|---:|---|
| **S0 inherited shortcut** | virgin normal **1.000** | geometry alone can masquerade as learned protocol |
| **S1 channel causality** | **1.000 → 0.000** after wire swap | physical routing really determines the result |
| **S2 naive raw repair** | greedy **0.000**, late reward **0.000** | the inherited road monopolizes the launcher |
| **S3 negative-image repair** | greedy **1.000**, late reward **1.000** | context-keyed expected-response subtraction lets real spatial writing grow an alternate road |
| **S3 no-write attacker** | late reward **0.492** | subtraction alone does not solve the task |
| **S3 global predictor attacker** | greedy **0.000** | this is not global normalization; prediction must be context keyed |
| **S3 wrong-context attacker** | greedy **0.000** | the predictor must receive the correct private context/corollary signal |
| **S4 predictor timescale** | slow **1.000**, fast **0.500** | a predictor that adapts too fast learns away the innovation needed for repair |

All S-series numbers above are means over **12 independent seeds**.

### The S3 launcher

The launch boundary no longer asks only which output is largest. It learns the response its own inherited body normally produces for the current cue and subtracts that prediction:

```text
innovation
  = log(observed launcher response)
  - predicted log(self-generated response | context)
```

The prediction model never sees the reward target. It is learned from self-generated cue responses. Rewarded counterfactual traffic still has to change the actual `JelloWorld` material. This distinction is why the no-write attacker stays near chance.

The biological analogies are deliberately separated:

- the **axon initial segment** motivates a launch / compartment boundary;
- mormyrid **corollary discharge / negative-image filtering** motivates prediction and cancellation of expected self-generated structure.

This repo does **not** claim the AIS performs the fish's negative-image computation.

## The S4 result may matter most

A very fast predictor (`0.20` tracking per observation in this toy) destroys the repair: final greedy performance falls to **0.500**. A much slower predictor (`0.0002`) preserves the useful residual and all 12 seeds reach **1.000**.

That gives the current structural hypothesis:

> **To distinguish an expected road from a newly relevant road, the expectation and the road cannot be rewritten on the same effective timescale.**

This reconnects JelloBrain to the wider fast / medium / slow operator thread: fast activity explores, slower material embodies history, and an expectation process must be slow enough not to erase novelty the instant it appears.

## Why the communication paper still belongs here

Stephens, Silbert & Hasson, *Speaker–listener neural coupling underlies successful communication* (PNAS, 2010, doi:10.1073/pnas.1008662107) remains inspiration for the dialogue attackers: useful coupling rather than synchrony, temporal/predictive structure, performance tracking, and perturbation/repair. It is not validation of the toy.

## Next hard gate — S5: two spatial interiors

S0–S4 intentionally isolate one launch boundary. The downstream receiver is trivial. S5 removes that convenience:

```text
private spatial A
    private x
       ↓
spatial integration
       ↓
AIS-like launcher ── external pulse ───────────┐
       │                                        │
       └── private corollary copy               v
                                      private spatial B
                                          private y
                                             ↓
                                    prediction / residual
                                             ↓
                                      action launcher
                                             ↓
                                         XOR reward
```

No table receiver. No globally assigned pulse meaning. No shared state. Then rerun the old communication attackers: wire swap, foreign crossplay, frozen plasticity, predictor-context scrambling, and repair.

That is where the question becomes sharp again:

> **Can geography itself carry a negotiable protocol once each body can subtract what it already expects from itself?**

## Claim boundary

The strongest safe statement currently is:

> **JelloBrain contains a spatial toy in which ordered traffic writes persistent operator geometry; a separate minimal signaling control in which initially meaningless pulses acquire pair-specific, repairable roles; and a spatial launch audit in which context-specific prediction of inherited responses enables reward-modulated local material writing to repair a remapped output channel.**

Not “it understands.” Not “it is a brain.” Not an explanation of the AIS or electric-fish circuitry. Not yet two full spatial communicators. Not yet “it thinks.”

That last question is why the repo has its name.
