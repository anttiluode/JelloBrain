# JelloBrain

### Can meaningless signals write a medium that later remembers order, changes context, computes — and eventually negotiate a private code with another medium?

**Live Phase I:** https://anttiluode.github.io/JelloBrain/  
**Live Phase II dialogue lab:** https://anttiluode.github.io/JelloBrain/dialogue.html

This repo takes the next step after [GelatinIsland](https://github.com/anttiluode/GelatinIsland). In that world, activity built geometry and geometry routed later activity. Here the traffic becomes a tiny artificial language.

> **Words are pokes that can become roads. Roads change what later pokes can do.**

Six meaningless primitives — `A B C D E F` — enter a writable 2-D dynamical substrate. A pseudoword is only a temporal sequence such as `ABC` or `ACB`. There are no embeddings, pretrained models, semantic labels, or stored word IDs. Fast excitation can be erased while slow directed material remains.

The first question was deliberately smaller than “can it think?”:

> **After the fast activity is gone, did the history of signals leave a functional, order-sensitive operator behind?**

That passed. Phase II then asked a different question:

> **If two private adaptive materials share only a narrow pulse channel, can useful pulse meaning emerge from interaction rather than being assigned?**

That now has a first positive control experiment too.

| **W2 geometry matters** | **1.00 → .50** after material shuffle | preserving all slow values but scrambling where/direction they live destroys the code |

These are **toy-model receipts**, not neuroscience results. The point is that every positive has an attacker and an exact failure mode. See [MODEL.md](MODEL.md).

## Phase II receipt — two private gels negotiate a pulse convention

The communication experiment is intentionally tiny. A sees private bit `x`. B sees private bit `y`. Exactly one of two meaningless pulse identities crosses A→B. B must output `x XOR y`. Neither side can inspect the other's slow material.

Run:

```bash
python dialogue_gates.py
```

The frozen receipt is `results/dialogue_gates.json`; the readable audit is [DIALOGUE_RESULT.md](DIALOGUE_RESULT.md).

| Gate | Result | What it says |
|---|---:|---|
| **D0 useful channel** | intact **1.000**, swapped wires **0.000**, foreign-code crossplay **0.475** | the learned channel is causal and pair-specific |
| **D1 predictive pulse** | post-pulse correct probability **0.458 → 0.996**, no-pulse stays **0.500** | the learned pulse becomes immediately useful to B; this is only a discrete predictive analogue |
| **D2 coupling tracks success** | **r = 0.885** across 48 pairs | stronger cue→pulse coupling accompanies better joint performance |
| **D3 repair** | channel swap **0.000 → 1.000** after adaptation | the pair can renegotiate after the physical mapping changes |
| **D4 private code / shared relation** | 10 pairs chose each opposite binary convention; foreign crossplay **0.474**, canonical relation **1.000** | raw pulse identity is private while task relation is shared |

The result I care about most is not the perfect XOR score. It is this:

```text
PAIR A1/B1 convention:  x0 -> pulse0, x1 -> pulse1
PAIR A2/B2 convention:  x0 -> pulse1, x1 -> pulse0

within pair: works
foreign raw crossplay: chance
canonical relation: shared
```

The token is not carrying a globally assigned meaning. Its role is built inside a particular interaction history.

## What is actually growing in Phase I?

The spatial gel is a grid with four directed conductivities per local edge. Recent activation leaves a medium-timescale eligibility trace. If neighbouring activity follows it in time, slow material is deposited on the corresponding directed edge.

```text
primitive pulses
      ↓
fast excitation + refractory state
      ↓
local temporal co-activity
      ↓
directed slow material
      ↓
new propagation operator
      ↓
future pulses take different trajectories
```

The slow material is the memory. The geometry is the weight matrix, except it is physically distributed over the world rather than stored as a dense array of learned word weights.

## Why W1 and W2 matter most

A weak version of this demo could “remember” merely because corpus A contained more `A`s than corpus B. W1 removes that escape hatch: both corpora contain exactly the same primitive counts. Only order differs.

Then W2 attacks another escape hatch. It takes every material value in a grown world, preserves the entire multiset, and only scrambles spatial position/direction. The held-out decoder falls from `1.00` to `0.50`. So in this implementation, the information is not just “how much material exists”; it is in **material arrangement as an operator**.

## Why the communication paper belongs here

Stephens, Silbert & Hasson, *Speaker–listener neural coupling underlies successful communication* (PNAS, 2010, doi:10.1073/pnas.1008662107) is useful as experimental inspiration, not proof of this model. They found spatial/temporal coupling between speaker and listener activity during successful story communication; coupling strongly diminished when linguistic communication was broken. Listener activity usually lagged the speaker, while some regions showed anticipatory coupling, and stronger anticipatory coupling tracked better comprehension.

Our D0–D4 tests borrow the shape of that logic: useful coupling rather than synchrony, temporal/predictive structure, performance tracking, and perturbation/repair. They do **not** reproduce the neuroscience experiment.

## The next hard gate

Phase II currently uses a deliberately minimal **protocol gel**:

```text
A: cue -> pulse slow material
B: cue × pulse -> action slow material
```

That is a signaling-game control, not yet the full spatial JelloWorld.

Now we have to remove that convenience and ask:

> **Can geography itself carry a negotiable protocol?**

Two full spatial `JelloWorld` bodies. Private cues enter spatial ports. A launcher emits a pulse through the narrow channel. B receives it at a boundary port, combines it with its private cue, and a spatial trajectory chooses an action launcher. Then rerun D0–D4.

If that fails, good: the protocol control worked but the spatial claim died. If it survives, the Phase-I geography has become a communication substrate.

## Claim boundary

The safe statement now is:

> **JelloBrain contains a spatial toy substrate in which ordered signals write persistent operator geometry, plus a separate minimal two-agent material control in which initially meaningless pulse identities acquire pair-specific, repairable functional roles through interaction.**

Not “it understands.” Not “it is a brain.” Not “speaker–listener coupling has been explained.” Not yet “it thinks.”

That last question is why the repo has its name.
