# Addressability ledger — we have been here before

JelloBrain S13–S15 should **not** be treated as the discovery that stable addressing / compartmentation can rescue a writable shared system. That motif has already appeared repeatedly in this repo lineage under different names.

This note exists to stop future work from rediscovering it and calling it new.

## Strict recurrences

I count **eight distinct project-level encounters** with essentially the same wall.

| lineage | local result | same wall in different clothing |
|---|---|---|
| **FunctionalArbors v0.8–v0.9** | delayed consequence could physically return to structure, but broad activity or even exact newborn-cell tags did not assign credit robustly | consequence is available, but the *causal address* of what should change is too coarse |
| **yrotisopeRweN G14–G15 / Twensday** | anonymous feedback works when external/internal coordinates remain stable; scrambling feature addresses collapses memory | semantics are optional; persistent addressability is not |

These are not eight independent discoveries. Several are direct descendants of the same program. The count is useful only as a warning: **this is a recurring invariant, not a new surprise.**

## What S15 actually adds

S15 is still useful because it diagnoses the **current JelloBrain failure**.

The executed upper-bound probe compares the same reversal cycle:

```text
SWAPPED -> NORMAL -> SWAPPED
```

with one collapsed slow sheet versus two cue-addressed slow bands.

The first four-seed run gave:

```text
collapsed additive
    1.000 -> 0.375 -> 1.000

separated additive
    1.000 -> 1.000 -> 1.000

separated + committed retirement
    1.000 -> 1.000 -> 1.000
```

The important part is that **retirement was unnecessary once the slow state was separated**. In this assay, the apparent need for negative plasticity was secondary to cross-context interference in the collapsed sheet.

That is a diagnosis, not a novelty claim.

## The frontier therefore moves

Do **not** spend the next gate proving again that an explicitly indexed second channel helps.

The unresolved step is:

> **Can a system under interference discover and stabilize its own useful address partition without being handed `cue -> band`?**

That is different from all of the positive controls above.

The progression should now be:

```text
S15  explicit cue -> anonymous stable band       upper-bound control
      PASS

S16  anonymous bands, no cue->band table
      reward + local eligibility must make
      different histories claim different bands

S17  remove pre-separated bands themselves
      ask whether local dynamics can create
      a channel / compartment / frequency / orientation
      that later behaves as a stable address
```

A semantic channel label is never required. A persistent physical distinction is.

## Stop line

The next result is interesting only if the **assignment** is embodied.

A controller-side lookup table saying

```text
cue 0 -> band 0
cue 1 -> band 1
```

would merely rebuild yrotisopeRweN Gate 14/15 with different nouns.

S16 must therefore keep any transient alarm/exploration state content-free. Which band becomes useful for which cue must be recoverable from the slow substrate after that transient state is erased.
